# DressLoop Verhuur

Build a complete responsive web application called DressLoop from scratch.

DressLoop is a Dutch peer-to-peer fashion rental marketplace where women can rent dresses from other users and rent out dresses from their own closet.

Think of the marketplace logic and ease of use of Vinted, but DO NOT copy Vinted visually.

The visual identity should instead feel like a modern editorial fashion website: minimal, calm, premium, trustworthy and community-driven.

The dresses and user photography will often already be colorful and visually busy, so the UI itself must stay extremely calm.

1. PRODUCT VISION

DressLoop should make these two actions immediately understandable:

Ik wil een jurk huren

and

Ik wil mijn jurk verhuren

A user should never need instructions to understand the platform.

Core brand values:

trustworthy

minimalistic

fashionable

sustainable

community

accessible

modern

The product should feel professional enough that someone would trust DressLoop with:

their money;

an expensive dress;

another person's dress;

their personal account.

Do not make it look like an early-stage prototype.

3. VISUAL DIRECTION

The design should feel like:

minimal editorial fashion website × modern marketplace

I want a VERY clean interface.

Do not make the design overly playful.

Do not fill every available space.

Whitespace is an important part of the design.

The visual inspiration is a minimalist editorial website with:

large whitespace;

clean typography;

strong grid;

thin lines;

editorial photography;

simple sections;

restrained use of color;

sophisticated layouts;

large photography;

minimal buttons;

very little visual clutter.

The website should feel considerably more premium than a standard marketplace template.

5. TYPOGRAPHY

Use a sophisticated but highly readable typography system.

The main UI typography should be a clean modern sans-serif.

It may have a subtle editorial/fashion character, but readability is more important.

Use one optional editorial accent typeface only for selected large marketing headlines if needed.

Do NOT use an extremely condensed display font throughout the interface.

Do NOT use five different fonts.

Create a consistent typography hierarchy:

The result should resemble a contemporary fashion editorial rather than a generic software dashboard.

19. PAYMENT LOGIC / UX

The renter pays during checkout.

The owner should NOT immediately receive the money.

The intended flow is:

Renter pays DressLoop

→ rental confirmed

→ dress is rented

→ dress returned successfully

→ owner receives payout.

Build the UI and statuses to support this.

IMPORTANT:

Do not claim that real escrow/payment holding exists unless a payment provider supporting this has actually been implemented.

For now build the product architecture and UI around this intended flow.

38. FINAL QUALITY CHECK

Before considering a page complete, ask:

Is this calm?

Is this obvious?

Is there enough whitespace?

Does the photography get enough attention?

Is there one obvious primary action?

Could a first-time user understand this without instructions?

Does it feel trustworthy enough to pay through?

Does it look like a real fashion company rather than an AI-generated template?

If not, improve it.

The final product should feel like:

a beautifully art-directed Dutch fashion platform with the simplicity of a mature marketplace.

Minimal.

Editorial.

Trustworthy.

Community-driven.

Fashion-forward.

The interface should be quiet.

The dresses should be loud.
